JLPT N2Unit 22

～わけがない

There is no way that

How to build it
plain form + わけがないN の / なA な + わけがない
What it means

Use plain form + わけがない for a strong denial: that cannot be true.

  • It says there is no reason for it to be true.
  • It's a strong, emotional denial.
  • Compare はずがない, which is a bit softer.
  • わけない alone can also mean 'it's easy'.
A flat 'no way'.
Compare
PatternFeeling
はずがないlogically unlikely
わけがないstrongly impossible
Example sentences
  1. 彼かれがそんなことを言いうわけがない。Kare ga sonna koto o iu wake ga nai.There's no way he would say such a thing.
  2. 一度いちども練習れんしゅうしていないのに、勝かてるわけがない。Ichido mo renshū shite inai no ni, kateru wake ga nai.We've never practised, so there's no way we could win.
  3. こんな高たかい物ものを買かえるわけがない。Konna takai mono o kaeru wake ga nai.There's no way I could buy something this expensive.
Common mistakes
  • 本当のはずわけがない。 → 本当のわけがない。
    Use の before わけがない with a noun.
