V て あります

Someone did it on purpose, and it stays that way

How to build it
N に N が V て ありますN は N に V て あります
What it means

～て あります describes a state left by someone's deliberate action, usually with a verb that takes を.

  • Someone did it on purpose, and the result is still there.
  • Use verbs that normally take を.
  • を changes to が, or to は for the topic.
  • Often it means something is ready: もう かって あります.
If you can imagine the person who did it, you want ～て あります.

Three ways to talk about an open window
JapaneseMeaning
まどが あいて います。It is open. No one's intention is implied.
まどが あけて あります。Someone opened it on purpose.
まどを あけて います。Someone is opening it now.
Example sentences
  1. カレンダーに 友ともだちの たんじょうびが 書かいて あります。Karendā ni tomodachi no tanjōbi ga kaite arimasu.My friend's birthday is written on the calendar.
  2. げんかんに 花はなが かざって あります。Genkan ni hana ga kazatte arimasu.Flowers have been set out in the entrance.
  3. パーティーの ビールは もう 買かって あります。Pātī no bīru wa mō katte arimasu.The beer for the party has already been bought.
Common mistakes
  • まどが あいて あります。 → まどが あけて あります。
    ～て あります needs the verb for doing it: あけます.
  • まどが あけて います。 → まどが あいて います。
    With ～て います and が, use the verb that happens by itself.
