この / その / あの N

This N, that N, that N over there

How to build it
この / その / あの Nこの / その / あの N2 は N1 のです
What it means

この, その and あの must be followed directly by a noun: この ほん = 'this book'. They cannot stand alone — use これ/それ/あれ for that. The near/far rules are the same as これ/それ/あれ.

  • They must be followed directly by a noun.
  • They cannot stand alone.
  • Near and far work the same as これ, それ, あれ.
  • This is just another way of saying the same sentence.
Same idea, two ways
WordNoun straight after?ExampleEnglish
これNoこれは わたしの ほんです。This is my book.
このYesこの ほんは わたしのです。This book is mine.
それNoそれは わたしの かさです。That is my umbrella.
そのYesその かさは わたしのです。That umbrella is mine.
あれNoあれは わたしの かばんです。That over there is my bag.
あのYesあの かばんは わたしのです。That bag over there is mine.
Example sentences
  1. この ほんは わたしのです。Kono hon wa watashi no desu.This book is mine.
  2. その かさは だれのですか。Sono kasa wa dare no desu ka.Whose is that umbrella?
  3. あの ひとは ミラーさんです。Ano hito wa Mirā-san desu.That person over there is Mr. Miller.
Common mistakes
  • このは わたしの ほんです。 → これは わたしの ほんです。
    この cannot stand alone. Use これ.
