Become: ～く なります, ～に なります

Become, get

How to build it
い-adjective: drop い + く なりますな-adjective / N + に なります
What it means

なります means 'become'. い-adjective: drop い + く (さむい → さむく なります). な-adjective and nouns: add に (げんきに なります, いしゃに なります). Gotcha: いい → よく なります.

  • なります means become.
  • いい changes to よく, from よい.
How each word type joins
Word typeWordWith なりますMeaning
いさむいさむく なりますget cold
いくらいくらく なりますget dark
いいいいよく なりますget better
なげんきげんきに なりますget well
なきれいきれいに なりますbecome clean
Nounいしゃいしゃに なりますbecome a doctor
Example sentences
  1. さむく なりました。Samuku narimashita.It's got cold.
  2. げんきに なりました。Genki ni narimashita.I've got better / I'm well again.
  3. いしゃに なりたいです。Isha ni naritai desu.I want to become a doctor.
Common mistakes
  • へやが きれく なりました。 → へやが きれいに なりました。
    きれい is a な-adjective, so use に.
  • ちょうしが いく なりました。 → ちょうしが よく なりました。
    いい becomes よく.
  • いしゃを なりたいです。 → いしゃに なりたいです。
    なります takes に, not を.
