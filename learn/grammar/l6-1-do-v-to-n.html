N を V

Do V to N

How to build it
N を V
What it means

を marks the direct object — the thing the action is done to. It is written を but read 'o'. The object comes before the verb: パンを たべます.

  • を marks the direct object: the thing the action is done to.
  • It is written を but read o.
  • The object comes before the verb.
Useful pairs
JapaneseEnglish
ごはんを たべます。I eat a meal.
みずを のみます。I drink water.
たばこを すいます。I smoke a cigarette.
テレビを みます。I watch television.
おんがくを ききます。I listen to music.
ほんを よみます。I read a book.
てがみを かきます。I write a letter.
パンを かいます。I buy bread.
しゃしんを とります。I take a photograph.
Example sentences
  1. ジュースを のみます。Jūsu o nomimasu.I drink juice.
  2. ほんを よみます。Hon o yomimasu.I read a book.
  3. てがみを かきました。Tegami o kakimashita.I wrote a letter.
Common mistakes
  • ともだちを あいます。 → ともだちに あいます。
    あいます takes に for the person you meet.
