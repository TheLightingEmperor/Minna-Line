～そうな N / ～そうに V

A ~-looking N / doing X in a ~ way

How to build it
～そうな + N～そうに + V
What it means

そう behaves like a な-adjective, so it becomes そうな before a noun and そうに before a verb.

  • そう conjugates like a な-adjective.
  • Before a noun it takes な, not の.
  • Before a verb it takes に.
If you know ～な ひと and ～に はなします, you already know this rule.
The three positions
PositionExampleMeaning
End of sentenceおいしそうですIt looks delicious.
Before a nounおいしそうな パンdelicious-looking bread
Before a verbおいしそうに たべますeats with obvious enjoyment
Example sentences
  1. おいしそうな りんごですね。Oishisō na ringo desu ne.What delicious-looking apples!
  2. モチは 楽たのしそうに 電車でんしゃを 見みて います。Mochi wa tanoshisō ni densha o mite imasu.Mochi is happily watching the trains.
  3. 新あたらしそうな 自転車じてんしゃが 駅えきの 前まえに あります。Atarashisō na jitensha ga eki no mae ni arimasu.There is a new-looking bicycle in front of the station.
Common mistakes
  • おいしそうの パン → おいしそうな パン
    そう takes な before a noun.
  • たのしそうな はなします。 → たのしそうに はなします。
    Use に before a verb.
