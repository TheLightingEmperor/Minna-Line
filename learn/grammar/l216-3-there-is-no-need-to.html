JLPT N3Unit 16

V dictionary + ことはない

There is no need to

How to build it
V dictionary + ことはない
What it means

ことはない tells someone that an action is unnecessary, usually to reassure them.

  • It reassures: you don't have to.
  • It can sound firm with そんなに.
  • Do not confuse it with Vたことはない.
  • Same idea as なくてもいい, but stronger.
Pair it with そんなに to comfort a friend: そんなに心配することはないよ。
Dictionary form or た-form
JapaneseMeaning
行くことはないthere is no need to go
行ったことはないI have never been
Example sentences
  1. かるいかぜだから、心配しんぱいすることはないよ。Karui kaze da kara, shinpai suru koto wa nai yo.It is only a light cold, so there is no need to worry.
  2. そんなに急いそいで病院びょういんに行いくことはない。Sonna ni isoide byōin ni iku koto wa nai.There is no need to rush to the hospital like that.
  3. 一回いっかい失敗しっぱいしたくらいで、なくことはありません。Ikkai shippai shita kurai de, naku koto wa arimasen.There is no need to cry over one failure.
Common mistakes
  • 心配したことはないよ。 → 心配することはないよ。
    With the た-form it means 'have never', not 'no need to'.
