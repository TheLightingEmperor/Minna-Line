Place に N が あります / います

There is N in a place

How to build it
Place に N が ありますPlace に N が います
What it means

に marks the place where something exists: へやに テーブルが あります. Use に, not で — で is for places where an ACTION happens. Ask with 'place に なにが ありますか' (things) or 'だれが いますか' (people).

  • に marks the location. が marks what exists.
  • Think: at this place, there is N.
  • Ask with なにが for things and だれが for people.
で vs に
ParticleMarksExampleEnglish
でWhere an action happensレストランで ごはんを たべます。I eat at the restaurant.
にWhere something existsレストランに たなかさんが います。Tanaka is at the restaurant.
Asking what is there
QuestionAnswerEnglish
へやに なにが ありますか。テーブルが あります。What is in the room? There is a table.
へやに だれが いますか。たなかさんが います。Who is in the room? Tanaka is.
Example sentences
  1. へやに テーブルが あります。Heya ni tēburu ga arimasu.There is a table in the room.
  2. こうえんに こどもが います。Kōen ni kodomo ga imasu.There are children in the park.
  3. れいぞうこに なにが ありますか。…ぎゅうにゅうと たまごが あります。Reizōko ni nani ga arimasu ka. …Gyūnyū to tamago ga arimasu.What's in the fridge? — There's milk and eggs.
Common mistakes
  • へやで テーブルが あります。 → へやに テーブルが あります。
    Existing takes に. で is for actions.
  • つくえの うえに ねこが あります。 → つくえの うえに ねこが います。
    Cats are alive, so use います.
