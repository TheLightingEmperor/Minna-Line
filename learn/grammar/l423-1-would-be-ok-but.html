JLPT N1Unit 23

～ならまだしも

... would be OK, but

How to build it
N + ならまだしもplain + ならまだしも
What it means

N / plain + ならまだしも says that one case is understandable but the other is not.

  • The first case is acceptable.
  • The second case is too much.
  • It is a spoken, critical pattern.
Same idea as ならいざ知らず, but more spoken.
Compare
PatternFeel
ならまだしもfirst case OK
ならいざ知らずfirst case possible, formal
Example sentences
  1. 子供こどもならまだしも、大人おとながそんなことで泣なくのか。Kodomo nara mada shi mo, otona ga sonna koto de naku no ka.A child is one thing, but would an adult cry over that?
  2. 一回いっかいならまだしも、三回さんかいも遅刻ちこくするとは。Ikkai nara mada shi mo, sankai mo chikoku suru to wa.Once would be OK, but being late three times!
  3. 冗談じょうだんならまだしも、本気ほんきで言いっているのか。Jōdan nara mada shi mo, honki de itte iru no ka.A joke would be OK, but are you saying this seriously?
