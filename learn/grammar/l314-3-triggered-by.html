JLPT N2Unit 14

～をきっかけに

Triggered by

How to build it
N + をきっかけに(して)N + がきっかけで
What it means

Use N + をきっかけに(して) when something started a change, habit or relationship.

  • The noun is the event that set things in motion.
  • The result is a new start or change.
  • がきっかけで is a close variant.
  • It works for both good and bad triggers.
One spark starts a new chapter.
Variants
FormExample
をきっかけに留学をきっかけに
がきっかけで留学がきっかけで
Example sentences
  1. 引ひっ越こしをきっかけに、料理りょうりを始はじめた。Hikkoshi o kikkake ni, ryōri o hajimeta.Moving house was the trigger for me to start cooking.
  2. 病気びょうきをきっかけに、生活せいかつを見直みなおした。Byōki o kikkake ni, seikatsu o minaoshita.Falling ill led me to rethink my lifestyle.
  3. その出来事できごとをきっかけに、二人ふたりはなかよくなった。Sono dekigoto o kikkake ni, futari wa nakayoku natta.That incident was how the two of them became friends.
Common mistakes
  • 留学にきっかけに → 留学をきっかけに
    Use を before きっかけに.
