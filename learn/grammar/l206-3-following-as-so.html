JLPT N3Unit 6

～にしたがって

Following, as ... so ...

How to build it
N + にしたがって (follow)V る / N + にしたがって (as)
What it means

Use ～にしたがって to say you follow something, or that one change goes along with another.

  • Follow: rules, orders, signs or advice.
  • As: one change moves along with another.
  • In the second use, both halves are gradual changes.
The verb したがう (to follow) is the root of this pattern.
Two uses
UseJapaneseMeaning
Follow地図にしたがって歩く。Walk following the map.
Followルールにしたがう。Follow the rules.
As高く登るにしたがって、寒くなる。The higher you climb, the colder it gets.
Example sentences
  1. あんないにしたがって、進すすんでください。Annai ni shitagatte, susunde kudasai.Please go ahead, following the signs.
  2. 駅えきに近ちかづくにしたがって、人ひとが多おおくなった。Eki ni chikazuku ni shitagatte, hito ga ōku natta.The closer we got to the station, the more people there were.
  3. 町まちの人口じんこうが増ふえるにしたがって、店みせも増ふえた。Machi no jinkō ga fueru ni shitagatte, mise mo fueta.As the town's population grew, so did the number of shops.
Common mistakes
  • 地図をしたがって歩く。 → 地図にしたがって歩く。
    The particle is に.
  • 駅に着くにしたがって、電話した。 → 駅に着いて、電話した。
    A one-time action doesn't fit.
