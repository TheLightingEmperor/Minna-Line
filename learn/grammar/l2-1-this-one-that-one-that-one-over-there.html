これ / それ / あれ

This one, that one, that one over there

How to build it
これ / それ / あれ は N ですこれ / それ / あれ は N1 の N2 です
What it means

これ is a thing near the speaker, それ a thing near the listener, and あれ a thing far from both. They stand alone as nouns, so they are followed by a particle like は — never by another noun. Ask about an object with 'これは なんですか'.

  • They stand alone as nouns, so は can follow directly.
  • Never put a noun straight after them.
Where the thing is
WordNearExampleEnglish
これThe speakerこれは ほんです。This is a book.
それThe listenerそれは しんぶんです。That is a newspaper.
あれFar from bothあれは コンピューターです。That over there is a computer.
Sentences to build
TypeExampleEnglish
Statementこれは かぎです。This is a key.
Yes/no questionこれは じしょですか。Is this a dictionary?
Negativeこれは ざっしじゃ ありません。This is not a magazine.
Ownerこれは わたしの ほんです。This is my book.
Asking whatそれは なんですか。What is that?
Asking whoseあれは だれの かばんですか。Whose bag is that over there?
Example sentences
  1. これは じしょです。Kore wa jisho desu.This is a dictionary.
  2. それは なんですか。Sore wa nan desu ka.What is that (near you)?
  3. あれは コンピューターです。Are wa konpyūtā desu.That over there is a computer.
Common mistakes
  • これ ほんは わたしのです。 → この ほんは わたしのです。
    これ stands alone. Use この before a noun.
