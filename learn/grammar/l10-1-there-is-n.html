N が あります / います

There is N

How to build it
N が ありますN が います
What it means

あります is used for things that don't move by themselves (objects, buildings — and plants, like trees). います is used for people and animals. The thing that exists takes が. Negatives: ありません / いません.

  • The thing that exists takes が.
  • Plants count as things, so a tree takes あります.
あります vs います
VerbNegativeUsed forExampleEnglish
ありますありませんObjects, buildings, plantsつくえが あります。There is a desk.
いますいませんPeople and animalsいぬが います。There is a dog.
Example sentences
  1. コンピューターが あります。Konpyūtā ga arimasu.There is a computer.
  2. おとこの ひとが います。Otoko no hito ga imasu.There is a man.
  3. いぬが います。Inu ga imasu.There is a dog.
Common mistakes
  • いぬが あります。 → いぬが います。
    Dogs are alive, so use います.
  • つくえが います。 → つくえが あります。
    A desk is a thing, so use あります.
