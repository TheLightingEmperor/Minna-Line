JLPT N3Unit 24

～だけでなく

Not only ~ but also

How to build it
N + だけでなくV・い-adj plain + だけでなくな-adj な + だけでなく
What it means

だけでなく adds a second item and usually ends with も.

  • The second half usually has も.
  • な-adjectives keep な.
  • Spoken form: だけじゃなくて.
  • Both items point the same way.
Link two good points in a review with だけでなく. It instantly sounds more fluent.

Example sentences
  1. この言葉ことばは若者わかものだけでなく、大人おとなも使つかう。Kono kotoba wa wakamono dake de naku, otona mo tsukau.Not only young people but adults use this word too.
  2. カランさんは話はなすだけでなく、書かくのも上手じょうずだ。Karan-san wa hanasu dake de naku, kaku no mo jōzu da.Karan is good not only at speaking but at writing too.
  3. このアプリは便利べんりなだけでなく、デザインもいい。Kono apuri wa benri na dake de naku, dezain mo ii.This app is not only handy but well designed too.
Common mistakes
  • 便利だけでなく、安全だ。 → 便利なだけでなく、安全だ。
    な-adjectives keep な before だけ.
