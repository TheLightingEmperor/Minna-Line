Making the object the topic: を becomes は

As for this thing, …

How to build it
N を + V → N は + V
What it means

When the object of a verb becomes the topic, it moves to the front and を changes to は: にもつを ここに おかないで ください → にもつは ここに おかないで ください. It's used to bring the object to the listener's attention or to contrast it. Never say をは.

  • The object is the thing an action is done to.
  • The topic is what a sentence is about.
  • Bring the object to the front and change を to は.
  • It draws attention to the object, or contrasts it.
  • Never say をは.
を becomes は
With をWith はMeaning
ここに にもつを おかないで ください。にもつは ここに おかないで ください。As for bags, please don't put them here.
かいしゃの しょくどうで ひるごはんを たべます。ひるごはんは かいしゃの しょくどうで たべます。As for lunch, I eat it in the company cafeteria.

Example sentences
  1. にもつは ここに おかないで ください。Nimotsu wa koko ni okanaide kudasai.(As for) bags, please don't put them here.
  2. ひるごはんは かいしゃの しょくどうで たべます。Hirugohan wa kaisha no shokudō de tabemasu.Lunch, I eat in the company cafeteria.
Common mistakes
  • にもつをは ここに おかないで ください。 → にもつは ここに おかないで ください。
    は replaces を. Never say をは.
