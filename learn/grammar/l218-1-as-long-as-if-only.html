JLPT N3Unit 18

～さえ～ば

As long as, if only

How to build it
N + さえ + V ばV ます-stem + さえすればい-adj く + さえあれば
What it means

さえ～ば says one condition is all you need for the result.

  • The second half is the good result.
  • Nothing else matters except this one condition.
  • さえ replaces が and を.
  • With verbs, use the stem plus さえすれば.
Memorise お金さえあれば and swap in anything you wish you had.
Forms
JapaneseMeaning
お金さえあればif only I had money
読みさえすればif you just read it
安くさえあればas long as it's cheap
静かでさえあればas long as it's quiet
Example sentences
  1. 単語たんごさえ覚おぼえれば、読よめるようになる。Tango sae oboereba, yomeru yō ni naru.As long as you memorise the words, you'll become able to read it.
  2. 辞書じしょさえあれば、一人ひとりでも勉強べんきょうできる。Jisho sae areba, hitori de mo benkyō dekiru.As long as I have a dictionary, I can study on my own.
  3. 説明せつめいを読よみさえすれば、答こたえはわかる。Setsumei o yomi sae sureba, kotae wa wakaru.If you just read the explanation, you'll know the answer.
Common mistakes
  • 辞書をさえあれば読める。 → 辞書さえあれば読める。
    さえ takes the place of が or を.
  • 読むさえすれば → 読みさえすれば
    Use the ます-stem before さえすれば.
