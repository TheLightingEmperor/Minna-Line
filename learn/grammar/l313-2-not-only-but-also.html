JLPT N2Unit 13

～のみならず

Not only... but also

How to build it
N / plain form + のみならずN + のみならず ～ も
What it means

Use N / plain form + のみならず in formal speech or writing for 'not just X but Y'.

  • It is a formal 'not only... but also'.
  • The second part usually has も.
  • It sounds like news, essays or speeches.
  • のみならず is the same as だけでなく in meaning.
A speech-style 'and even more'.
Written style
PatternMeaning
のみならずnot only
だけでなくnot only (neutral)
Example sentences
  1. 彼かれは、国内こくないのみならず、海外かいがいでも有名ゆうめいだ。Kare wa, kokunai nomi narazu, kaigai demo yūmei da.He is famous not only at home but also abroad.
  2. この問題もんだいは、大人おとなのみならず、子こどもにも関係かんけいがある。Kono mondai wa, otona nomi narazu, kodomo ni mo kankei ga aru.This problem concerns not just adults but children too.
  3. 地震じしんは、家いえのみならず、道路どうろにも被害ひがいを与あたえた。Jishin wa, ie nomi narazu, dōro ni mo higai o ataeta.The earthquake damaged not only houses but also roads.
Common mistakes
  • 国内のみならない → 国内のみならず
    The negative ず-form is fixed.
