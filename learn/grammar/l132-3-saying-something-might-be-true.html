Plain form + かもしれません

Saying something might be true

How to build it
V plain + かもしれませんい-adj + かもしれませんな-adj / N + かもしれません
What it means

かもしれません after a plain form means might, and it is less certain than でしょう.

  • It means there is a chance, perhaps fifty-fifty.
  • It joins in the same way as でしょう.
  • な-adjectives and nouns drop だ.
  • もしかしたら at the start makes it even less sure.
かもしれません comes with an escape route: it might not happen either.

Example sentences
  1. モチは もう ねて いるかもしれません。Mochi wa mō nete iru kamo shiremasen.Mochi might already be asleep.
  2. 午後ごごから 雨あめに なるかもしれません。Gogo kara ame ni naru kamo shiremasen.It might start to rain from this afternoon.
  3. あの 人ひとは たなかさんの お父とうさんかもしれません。Ano hito wa Tanaka-san no otōsan kamo shiremasen.That person might be Tanaka-san's father.
Common mistakes
  • あめだかもしれません。 → あめかもしれません。
    Nouns drop だ.
  • いきますかもしれません。 → いくかもしれません。
    Use the plain form.
