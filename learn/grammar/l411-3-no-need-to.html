JLPT N1Unit 11

～までもない

No need to ...

How to build it
V dictionary form + までもないV dictionary form + までもなく
What it means

V dictionary form + までもない says that it is not necessary to do something, because the answer is obvious.

  • The result is obvious, so the action is not needed.
  • Often used with 言う, 調べる, 確かめる.
  • Not for things that are impossible.
言うまでもなく is the most common phrase.
Compare
PatternFeel
までもないnot needed
ことはないno need, softer
Example sentences
  1. 調しらべるまでもなく、答こたえは明あきらかだ。Shiraberu made mo naku, kotae wa akiraka da.There's no need to look it up; the answer is clear.
  2. 言いうまでもなく、健康けんこうが一番いちばんだ。Iu made mo naku, kenkō ga ichiban da.Needless to say, health comes first.
  3. わざわざ行いくまでもない。電話でんわで十分じゅうぶんだ。Wazawaza iku made mo nai. Denwa de jūbun da.No need to go all the way. A phone call is enough.
Common mistakes
  • 行ったまでもない。 → 行くまでもない。
    Use the dictionary form.
