JLPT N1Unit 17

～ならいざ知らず

... might be fine, but

How to build it
N + ならいざ知らずplain + ならいざ知らず
What it means

N / plain + ならいざ知らず says that in one case it could be accepted, but not in another.

  • The first case is possibly fine.
  • The second case is not acceptable.
  • It carries disapproval or surprise.
Use it for 'child vs adult', 'amateur vs pro'.
Compare
PatternFeel
ならいざ知らずone case OK, the other not
はともかくset aside
Example sentences
  1. 子供こどもならいざ知しらず、大人おとながそんなことをするとは恥はずずかしい。Kodomo nara iza shirazu, otona ga sonna koto o suru to wa hazukashii.It might be fine for a child, but it's embarrassing for an adult to do so.
  2. 素人しろうとならいざ知しらず、プロが間違まちがえるのは許ゆるされない。Shirōto nara iza shirazu, puro ga machigaeru no wa yurusarenai.An amateur is one thing, but a pro making mistakes is unacceptable.
  3. 昔むかしならいざ知しらず、今いまの時代じだいでは通用つうようしない。Mukashi nara iza shirazu, ima no jidai de wa tsūyō shinai.It might have worked in the past, but it won't now.
Common mistakes
  • 子供ならいざ知らず、大人も許される。 → 子供ならいざ知らず、大人は許されない。
    The second case must be worse.
