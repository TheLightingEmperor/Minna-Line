なんの N

What kind of N? N about what?

How to build it
なんの N ですかN1 の N2 です
What it means

なんの + noun asks what something is about or what type it is: なんの ほん = 'a book about what?'. Compare だれの + noun, which asks whose it is. Answer with 'N1 の N2'.

  • なんの always comes right before a noun.
  • Answer with N1 の N2.
なんの vs だれの
WordAsksExampleEnglish
なんのThe topic or typeこれは なんの ほんですか。What is this book about?
だれのThe ownerこれは だれの ほんですか。Whose book is this?
Example sentences
  1. これは なんの ほんですか。…くるまの ほんです。Kore wa nan no hon desu ka. …Kuruma no hon desu.What is this book about? — It's a book about cars.
  2. それは なんの ざっしですか。…カメラの ざっしです。Sore wa nan no zasshi desu ka. …Kamera no zasshi desu.What magazine is that? — It's a camera magazine.
  3. これは なんの CDですか。…にほんごの CDです。Kore wa nan no shīdī desu ka. …Nihongo no shīdī desu.What CD is this? — It's a Japanese-language CD.
