JLPT N2Unit 7

～に応じて

In line with; depending on

How to build it
N + に応じてN + に応じた + N
What it means

Use N + に応じて when something changes or is chosen to match a situation, need or amount.

  • Something changes or is chosen to match a condition.
  • The condition can be a need, a size or a season.
  • Use に応じた + noun to modify a noun.
  • The second half is usually a change or a choice.
Think of a dial that turns as the situation changes.
Examples
JapaneseMeaning
収入に応じた税金tax matched to income
必要に応じて連絡するcontact if needed
Example sentences
  1. 季節きせつに応おうじて、メニューが変かわります。Kisetsu ni ōjite, menyū ga kawarimasu.The menu changes according to the season.
  2. お客きゃくさんの好このみに応おうじて、味あじを選えらべます。Okyaku-san no konomi ni ōjite, aji o erabemasu.You can choose the flavour to suit your taste.
  3. 収入しゅうにゅうに応おうじて、税金ぜいきんが決きまる。Shūnyū ni ōjite, zeikin ga kimaru.Tax is set according to income.
Common mistakes
  • 予算を応じて選ぶ。 → 予算に応じて選ぶ。
    Use に before 応じて.
