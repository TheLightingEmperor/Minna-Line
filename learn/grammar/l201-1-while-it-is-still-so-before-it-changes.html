JLPT N3Unit 1

～うちに

While it is still so, before it changes

How to build it
V る / V ている + うちにいA / なA な + うちにN の + うちに
What it means

Use ～うちに when you should act while a state lasts, because that state will soon change.

  • The state will end soon, so act now.
  • The second half is often a wish, plan or request.
  • ～ているうちに: a change happens without you noticing.
Ask yourself: will this state end soon? If yes, うちに fits.

Two uses
JapaneseMeaning
熱いうちに食べよう。Let's eat while it's hot.
話しているうちに、友だちになった。As we talked, we became friends.
Example sentences
  1. 若わかいうちに、いろいろな国くにへ行いってみたい。Wakai uchi ni, iroiro na kuni e itte mitai.I want to visit many countries while I'm young.
  2. あたたかいうちに、どうぞ食たべてください。Atatakai uchi ni, dōzo tabete kudasai.Please eat it while it's warm.
  3. 音楽おんがくを聞きいているうちに、眠ねむくなった。Ongaku o kiite iru uchi ni, nemuku natta.I got sleepy while listening to music.
Common mistakes
  • けっこんするうちに、お金をためたい。 → けっこんする前に、お金をためたい。
    A single future event takes 前に, not うちに.
