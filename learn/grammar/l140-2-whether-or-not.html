Plain + か どうか

Whether or not ~

How to build it
V / いA plain + か どうかなA / N + か どうか
What it means

For a yes-no question inside a sentence, with no question word, use the plain form + か どうか.

  • か どうか means whether or not.
  • Use it only when there is no question word.
  • Nouns and な-adjectives drop だ here too.
Look for a question word first: if there is one, use か. If not, use か どうか.

Example sentences
  1. マリアさんが 来くるか どうか、わかりません。Maria-san ga kuru ka dō ka, wakarimasen.I don't know whether Maria is coming.
  2. この 魚さかなが 新あたらしいか どうか、店みせの 人ひとに 聞ききました。Kono sakana ga atarashii ka dō ka, mise no hito ni kikimashita.I asked the shop assistant whether this fish is fresh.
  3. 明日あしたが 休やすみか どうか、知しって いますか。Ashita ga yasumi ka dō ka, shitte imasu ka.Do you know whether tomorrow is a day off?
Common mistakes
  • どこへ いくか どうか、しりません。 → どこへ いくか、しりません。
    A question word uses か alone.
  • やすみだか どうか、しりません。 → やすみか どうか、しりません。
    Drop だ after a noun.
