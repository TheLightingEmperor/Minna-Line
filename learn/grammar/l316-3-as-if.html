JLPT N2Unit 16

～かのようだ

As if

How to build it
plain form + かのようだN + である + かのようだ
What it means

Use plain form + かのようだ when something looks or acts as if a thing were true, when it isn't.

  • It means as if, with a feeling of exaggeration.
  • The first half is not necessarily true.
  • まるで often comes first.
  • かのように modifies verbs; かのような modifies nouns.
A comparison that feels exaggerated: 'as if...'.
Forms
FormExample
かのようだ夢のようだ → 夢を見ているかのようだ
かのように知らなかったかのように
かのような知らなかったかのような顔
Example sentences
  1. 彼かれは何なにも知しらなかったかのような顔かおをしていた。Kare wa nani mo shiranakatta ka no yō na kao o shite ita.He had a face as if he knew nothing.
  2. 今日きょうは春はるが来きたかのように暖あたたかい。Kyō wa haru ga kita ka no yō ni atatakai.It's warm today, as if spring had come.
  3. まるで夢ゆめを見みているかのようだった。Marude yume o mite iru ka no yō datta.It was just as if I were dreaming.
Common mistakes
  • まるで夢かのようだ → まるで夢であるかのようだ
    With a noun, use である before かのようだ.
