Plain + はずです

Should be ~, I'm sure that ~ (based on reasons)

How to build it
V / いA plain + はずですなA な + はずですN の + はずです
What it means

～はずです states what you firmly expect from good reasons, and it is about facts rather than your own plans.

  • はず works like a noun, so it takes な and の.
  • You need a reason for your expectation.
  • はずが ありません means it can't be true.
Add the reason first with ～から, then finish with ～はずです.
Forms before はずです

How sure are you?
JapaneseMeaning
くる でしょうThey will probably come.
くる はずですThey should come, I have good reasons.
こない はずですThey shouldn't be coming.
くる はずが ありませんThere's no way they'll come.
Example sentences
  1. モチは 今いま 駅えきに いる はずです。Mochi wa ima eki ni iru hazu desu.Mochi should be at the station now.
  2. 今日きょうは 土曜日どようびですから、銀行ぎんこうは 休やすみの はずです。Kyō wa doyōbi desu kara, ginkō wa yasumi no hazu desu.It's Saturday, so the bank should be closed.
  3. 高たかい 店みせですから、おいしい はずです。Takai mise desu kara, oishii hazu desu.It's an expensive restaurant, so it should be good.
Common mistakes
  • やすみ はずです。 → やすみの はずです。
    A noun takes の before はず.
  • ひまだ はずです。 → ひまな はずです。
    A な-adjective keeps な.
