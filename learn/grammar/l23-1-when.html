JLPT N5Lesson 23

～とき

When

How to build it
V plain form / い-adjective + ときな-adjective + な ときN + の とき
What it means

とき ('time') is a noun, so it's modified like one: verb plain form + とき (みちを わたる とき), い-adjective + とき (ねむい とき), な-adjective + な とき (ひまな とき), noun + の とき (こどもの とき). The clause before とき sets the time of the main sentence.

  • とき means time, and it is a noun.
  • So words join it the same way they join any noun.
  • The とき part sets the time of the main sentence.
How each word type joins
Word typeExampleMeaning
Verbみちを わたる ときwhen crossing the road
いねむい ときwhen sleepy
なひまな ときwhen free
Nounこどもの ときwhen I was a child
Example sentences
  1. ひまな とき、えいがを みます。Hima na toki, eiga o mimasu.When I'm free, I watch movies.
  2. こどもの とき、よく そとで あそびました。Kodomo no toki, yoku soto de asobimashita.When I was a child, I often played outside.
  3. ねむい とき、コーヒーを のみます。Nemui toki, kōhī o nomimasu.When I'm sleepy, I drink coffee.
Common mistakes
  • しずかの とき、ほんを よみます。 → しずかな とき、ほんを よみます。
    な-adjectives take な before とき.
  • ねむいの とき、コーヒーを のみます。 → ねむい とき、コーヒーを のみます。
    い-adjectives join とき directly.
