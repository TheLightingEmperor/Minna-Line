JLPT N2Unit 6

～さえ～ば

If only; as long as

How to build it
N + さえ + V ばV ます-stem + さえすれば
What it means

Use N + さえ + V ば to say one small condition is enough for the result.

  • It names the single condition that is enough.
  • The ば-form comes after it.
  • With a verb, use ます-stem + さえすれば.
  • With a na-adjective, use でさえあれば.
One condition is enough. Everything else can be forgotten.
Forms
TypeExample
Nounお金さえあれば
Verb聞きさえすれば
I-adjective安くさえあれば
Na-adjective静かでさえあれば
Example sentences
  1. 時間じかんさえあれば、旅行りょこうに行いきたい。Jikan sae areba, ryokō ni ikitai.If only I had the time, I'd like to travel.
  2. この薬くすりを飲のみさえすれば、すぐ治なおります。Kono kusuri o nomi sae sureba, sugu naorimasu.You'll recover soon if you just take this medicine.
  3. 子こどもが元気げんきでさえあれば、何なにもいらない。Kodomo ga genki de sae areba, nani mo iranai.As long as my child is healthy, I need nothing else.
Common mistakes
  • 天気さえよいば行く。 → 天気さえよければ行く。
    Use the ば-form of the adjective: よければ.
