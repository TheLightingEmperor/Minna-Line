～なくして

Without ...

How to build it
N + なくして(は) + negative
What it means

N + なくして(は) + negative says that without N, something cannot happen.

  • N is a necessary condition.
  • The second half says something is impossible.
  • It is a speech and essay style.
Pair it with 〜はない or 〜できない.
Compare
PatternFeel
なくしてwithout N, impossible
なしにwithout doing
Example sentences
  1. 努力どりょくなくして、成功せいこうはない。Doryoku nakushite, seikō wa nai.Without effort, there is no success.
  2. 皆様みなさまの協力きょうりょくなくしては、この計画けいかくは実現じつげんしなかった。Minasama no kyōryoku nakushite wa, kono keikaku wa jitsugen shinakatta.Without everyone's cooperation, this plan wouldn't have come true.
  3. 信頼しんらいなくして、友情ゆうじょうは成なり立たたない。Shinrai nakushite, yūjō wa naritatanai.Without trust, friendship cannot stand.
Common mistakes
  • 努力なくして、成功がある。 → 努力なくして、成功はない。
    The ending must be negative.
