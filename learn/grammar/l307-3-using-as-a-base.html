JLPT N2Unit 7

～をもとに

Using as a base

How to build it
N + をもとに(して)N + をもとにした + N
What it means

Use N + をもとに(して) to say you made something new from a source such as facts, a story or data.

  • The noun is the material you start from.
  • What you make is new: a film, a plan, a book.
  • Use をもとにした + noun before a noun.
  • It is close to に基づいて but looser.
Raw material in, new creation out.
もとに or に基づいて
PatternFeeling
を元にa source you build from
に基づいてa rule or fact you follow
Example sentences
  1. 実話じつわをもとに、映画えいがが作つくられた。Jitsuwa o moto ni, eiga ga tsukurareta.The film was made based on a true story.
  2. 祖母そぼのレシピをもとに、スープを作つくった。Sobo no reshipi o moto ni, sūpu o tsukutta.I made the soup based on my grandmother's recipe.
  3. アンケートの結果けっかをもとに、メニューを考かんがえた。Ankēto no kekka o moto ni, menyū o kangaeta.We planned the menu based on the survey results.
Common mistakes
  • データにもとに計画した。 → データをもとに計画した。
    Use を before もとに.
