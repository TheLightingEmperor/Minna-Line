JLPT N4Lesson 46

V た + ばかりです

Only just did X (it feels recent)

How to build it
V た + ばかりですV た + ばかりの + N
What it means

V た + ばかりです says something happened recently in the speaker's mind, even if weeks or months have passed.

  • The speaker feels it was recent, whatever the calendar says.
  • ばかり works like a noun, so it takes の or な.
Use it as an excuse: にほんに きた ばかりですから。
ところ or ばかり?
Time gap～た ところです～た ばかりです
A moment agoYesYes
Last weekNoYes
Last monthNoYes
Last yearNoYes
Example sentences
  1. モチは 先月せんげつ 駅長えきちょうに なった ばかりです。Mochi wa sengetsu ekichō ni natta bakari desu.Mochi only became stationmaster last month.
  2. 買かった ばかりの くつが よごれました。Katta bakari no kutsu ga yogoremashita.The shoes I'd only just bought got dirty.
  3. 先週せんしゅう 来きた ばかりなので、まだ 道みちが わかりません。Senshū kita bakari na node, mada michi ga wakarimasen.I only came last week, so I don't know the roads yet.
Common mistakes
  • かった ばかり くつ → かった ばかりの くつ
    Use の before a noun.
  • きた ばかりので → きた ばかりなので
    Use な before ので.
