～ば～ほど

The more ..., the more ...

How to build it
V ば + V る + ほどいA ければ + いA い + ほどなA なら + なA な + ほど
What it means

Use the ば-form and then the dictionary form + ほど to say that as one thing increases, so does another.

  • The same word appears twice.
  • The second half grows together with the first.
  • The ば part can be dropped: 考えるほど.
  • It works only for things that can increase.
Practise it as a chain: 話せば話すほど上手になる。
How each word type connects
TypeJapanese
Verb飲めば飲むほど
I-adjective安ければ安いほど
Na-adjective静かなら静かなほど
Example sentences
  1. このカレーは食たべれば食たべるほどからくなる。Kono karē wa tabereba taberu hodo karaku naru.The more you eat this curry, the spicier it gets.
  2. やさいは新あたらしければ新あたらしいほどおいしい。Yasai wa atarashikereba atarashii hodo oishii.The fresher the vegetables, the tastier they are.
  3. 作つくり方かたはかんたんならかんたんなほどいい。Tsukurikata wa kantan nara kantan na hodo ii.The simpler the method, the better.
Common mistakes
  • 安いば安いほどいい。 → 安ければ安いほどいい。
    いA take ければ.
  • 静かば静かほどいい。 → 静かなら静かなほどいい。
    なA use なら, then な.
