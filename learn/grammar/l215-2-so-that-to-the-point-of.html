～ほど (degree)

So ~ that, to the point of

How to build it
V plain + ほど + stateい-adj + ほど + statenumber + ほど
What it means

ほど shows how far a state goes by comparing it with an extreme result, and after a number it means 'about'.

  • The clause before ほど paints an extreme picture.
  • The picture does not need to be literally true.
  • After a number, ほど means about.
  • Do not use ほど with a point in time.
Collect a few set phrases such as 死ぬほど and 信じられないほど. You will hear them daily.
Two uses
JapaneseMeaning
なきたいほど痛いso painful I want to cry
死ぬほど疲れたtired to death
三日ほど続くlast about three days
千円ほどかかるcost about 1,000 yen
Example sentences
  1. 今日きょうは息いきができないほど風かぜが強つよい。Kyō wa iki ga dekinai hodo kaze ga tsuyoi.The wind today is so strong I can hardly breathe.
  2. 川かわの水みずは、そこが見みえるほどきれいだ。Kawa no mizu wa, soko ga mieru hodo kirei da.The river water is so clean you can see the bottom.
  3. 雨あめは三日みっかほど続つづいた。Ame wa mikka hodo tsuzuita.The rain continued for about three days.
Common mistakes
  • 三時ほどに来る。 → 三時ごろに来る。
    A clock time takes ごろ. ほど is for amounts.
