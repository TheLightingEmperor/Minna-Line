The ば form

If: a condition for a result

How to build it
Verbs: え row + ばい-adj: ～ければな-adj / N: ～なら
What it means

The ば form states the condition needed for what follows.

  • It says what is needed for the result to happen.
  • The ば part comes first, then the result.
  • After an action verb, don't put a request or plan. Use たら.
  • Question word + ば いいですか asks for advice, like たら いいですか.
When in doubt, use たら. Use ば when the first half is the key condition.

Example sentences
  1. 駅えきに 近ちかければ、この へやを 借かります。Eki ni chikakereba, kono heya o karimasu.If it's near the station, I'll rent this room.
  2. 時間じかんが あれば、てつだいます。Jikan ga areba, tetsudaimasu.If I have time, I'll help.
  3. 雨あめが ふらなければ、海うみへ 行いきます。Ame ga furanakereba, umi e ikimasu.If it doesn't rain, I'll go to the sea.
Common mistakes
  • いいければ、きて ください。 → よければ、きて ください。
    いい changes to よ: よければ.
  • やすいば かいます。 → やすければ かいます。
    い-adjectives change い to ければ.
  • しごとが おわれば、でんわして ください。 → しごとが おわったら、でんわして ください。
    A request after a verb's ば sounds wrong. Use たら.
