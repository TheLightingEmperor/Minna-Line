JLPT N3Unit 5

～たびに

Every time

How to build it
V る + たびにN の + たびに
What it means

Use ～たびに to say that each time one thing happens, the same result follows.

  • Repetition is the core idea.
  • The second half is the same result each time.
  • Daily routines don't use it. Use 毎朝 and so on.
  • It often carries a feeling, like memory or surprise.
Pair it with 思い出す, its classic partner.
Saying every time
PatternFeeling
たびにEach time, often with a feeling
といつもAlways, as a general fact
毎朝A regular schedule
Example sentences
  1. この駅えきを通とおるたびに、学生がくせいのころを思おもい出だす。Kono eki o tōru tabi ni, gakusei no koro o omoidasu.Every time I pass through this station, I remember my student days.
  2. 旅行りょこうのたびに、地元じもとの料理りょうりを食たべる。Ryokō no tabi ni, jimoto no ryōri o taberu.Every time I travel, I eat the local food.
  3. モチは電車でんしゃが来くるたびに、元気げんきよく鳴なく。Mochi wa densha ga kuru tabi ni, genki yoku naku.Every time a train comes, Mochi gives a lively meow.
Common mistakes
  • 朝起きるたびに、歯をみがく。 → 毎朝、歯をみがく。
    A daily routine doesn't need たびに.
  • 見たたびに、思い出す。 → 見るたびに、思い出す。
    Use the dictionary form.
